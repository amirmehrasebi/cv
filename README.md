## ✨ Features

- **Dark / Light Mode** – per Klick umschaltbar, wird gespeichert
- **Scroll Reveal Animationen** – Elemente erscheinen beim Scrollen
- **Vollständiger Lebenslauf** – Timeline, Kompetenzen, Kontakt
- **Portfolio-Sektion** – bereit für eigene Projekte
- **Responsive** – optimiert für Desktop, Tablet & Mobil
- **GitHub Pages ready** – keine Build-Tools nötig

---

## 🚀 GitHub Pages einrichten

1. Repository erstellen: `amirmehrasebi.github.io` (oder beliebiger Name)
2. Alle Dateien hochladen
3. **Settings → Pages → Source: main branch / root**
4. Fertig — die Seite ist live!

## 📝 Anpassungen

| Was | Wo |
|-----|-----|
| Profilfoto einfügen | `index.html` → `.photo-placeholder` durch `<img src="foto.jpg">` ersetzen |
| Portfolio-Arbeiten | `index.html` → Sektion `id="portfolio"` |
| GitHub-URL | `index.html` → Kontakt-Sektion |
| Farben | `style.css` → CSS-Variablen am Anfang |
